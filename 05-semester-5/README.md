
# Module 04 - If-Else Practice

## Overview
This module focuses on conditional statements
in Java to make decisions based on given conditions.

## Learning Objectives
- Understand if and else statements.
- Apply logical and comparison operators.
- Evaluate multiple conditions.
- Solve real-world problems using conditions.

## Practice Exercises

| No. | Exercise | Description |
|---|---|---|
| 01 | Retired Staff | Check employee retirement eligibility |
| 02 | Age Checker | Identify age categories |
| 03 | Pass or Fail | Evaluate student examination results |

## Concepts Used
- Scanner
- Variables
- If-Else
- Comparison Operators
- Logical Operators

## Technologies
- Java
- JDK
- VS Code

## Learning Outcome
Able to write Java programs using conditional
statements to solve basic decision-making problems.
